Browser extension settings

Allow access to the FootprintX server

Your browser needs your permission for the extension to contact the FootprintX server. This grants access to the FootprintX server only — not to the websites you visit.

Account

In FootprintX, open Settings → Browser extension → “Create link code”, then type the code here. Your password is never entered into the extension.

Protection

Share security events with your dashboard (optional)

When on, these events are sent to your FootprintX account so they appear in your dashboard: a known-threat warning shown, a suspicious-site warning shown, or a site you visited later being listed as a threat. Each event contains the site’s domain name, the warning type and the time. Routine visits, full addresses (paths and queries), page content and your browsing history are never sent.

Data stored on this device

How checks work: for each site, the extension computes a SHA-256 hash of the domain name (and its parent domains) and sends only the first 8 hex characters to FootprintX. The server replies with the full hashes of any listed sites that share that prefix, and the extension compares them on your device. Account awareness separately sends the normalized domain to your authenticated FootprintX backend to match your inventory. These lookups are not stored as visit history. Paths, queries, and page contents are never sent.
